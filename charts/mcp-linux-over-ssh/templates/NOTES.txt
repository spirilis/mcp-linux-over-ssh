     apiVersion: api.kagent.dev/v1alpha3
     kind: RemoteMCPServer
     metadata:
       name: {{ $fullname }}
     spec:
       description: Run commands on remote hosts through persistent shell sessions
       url: {{ include "mcp-linux-over-ssh.serviceURL" . }}
       actorJwt:
         audiences: ["{{ include "mcp-linux-over-ssh.actorAudience" . }}", "kagent-agent-info"]
         expirationSeconds: 900

  kagent cannot list this server's tools in its UI (its control plane has no actor identity);
  agents list them at run time.
